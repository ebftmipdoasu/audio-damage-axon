## Overview

Audio Damage Axon is a unique drum synthesizer and sequencer that uses a neural-network-inspired architecture to generate evolving, semi-random rhythmic patterns.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Axon** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Neural Sequencer** | Pattern generation inspired by neural network topology |
| **Drum Synthesis** | Six integrated drum synth voices with per-voice tuning |
| **Evolution** | Patterns mutate and evolve over time for organic variation |
| **CV/Gate Output** | Route rhythmic triggers to external hardware or plugins |
